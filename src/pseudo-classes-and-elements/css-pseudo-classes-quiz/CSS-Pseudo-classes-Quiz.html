الفئات والعناصر الزائفة

اختبار الفئات الزائفة Pseudo-classes في CSS

إختبار

  1. ما هي الفئات الزائفة (pseudo-classes) ؟




    هي كلمات مفتاحية تُضاف إلى المُحدِّد (selector) لتنسيق عنصر بناءً على حالته.

  2. ما هي الفئة الزائفة (pseudo-class) التي تُطبَّق عندما يتم توجيه جهاز تأشير فوق عنصرٍ ما؟




    :hover

  3. ما هو العنصر الزائف (pseudo-element) الذي يتيح لك تنسيق الحرف الأول من فقرة ما؟




    ::first-lettre

  4. ما هي الفئة الزائفة (pseudo-class) التي تُغيِّر نمط العنصر أثناء النقر عليه؟




    :active

  5. ما هي الفئة الزائفة (pseudo-class) التي تُستخدم لتنسيق عنصر ما عندما يكون جاهزاً لتلقي مدخلات المستخدم، مثل حقل نصي عند النقر عليه أو الانتقال إليه باستخدام مفتاح Tab ؟




    :focus

  6. أي من قواعد CSS التالية تضيف النص ملاحظة: بشكل صحيح أمام كل عنصر فقرة (paragraph element) يحمل الفئة (class) المسماة note ؟




    
p.note::before {
 content: "ملاحظة:";
}

  7. ما هي الفئة الزائفة (pseudo-class) التي تُطبَّق على حقل الإدخال عند اختياره أو تفعيله؟




    :checked

  8. أيٌّ مما يلي يُمثّل الصيغة الصحيحة لتنسيق العنصر الأخير في قائمة؟




    
li:last-child {
 color: blue;
}

  9. ما هي الفئة الزائفة (pseudo-class) التي تستهدف حقول الإدخال غير المطلوبة (التي لا يلزم تعبئتها)؟




    :optional

  10. ما الذي تقوم به الفئة الزائفة :disabled ؟




    تُطبِّق تنسيقات على العناصر غير المتاحة لتفاعل المستخدم.

  11. أي فئة زائفة (pseudo-class) تُطبَّق عندما يستوفي حقل الإدخال في نموذجٍ ما معايير التحقق الخاصة به؟




    :valid

  12. أيٌّ من هذه الخيارات لا يُعدّ فئةً زائفةً (pseudo-class) متعلقةً بالموقع؟




    :current

  13. أيٌّ مما يلي يختار عنصر القائمة الثالث؟




    
li:nth-child(3) {
 color: red;
}

  14. ما هي العناصر التي ستظهر باللون الأزرق blue عند استخدام كود CSS التالي؟

    
p:is(.blue, .highlight) {
 color: blue;
}
            



    
<p class="blue">الفقرة 1</p>
<p class="highlight">الفقرة 2</p>

  15. ما الذي تفعله الفئة الزائفة :not() ؟




    تختار العناصر التي لا تطابق مُحدِّدًا معينًا.

  16. ما الذي تقوم به قاعدة CSS التالية؟

    
p:first-of-type {
 font-style: italic;
}



    يختار أول عنصر p داخل حاوية أب.

  17. ما الذي تقوم به الفئة الزائفة :last-of-type ؟




    يختار العنصر الابن الأخير من نوعٍ محددٍ داخل عنصره الأب.

  18. أي فئة زائفة (pseudo-class) تُستخدم لاختيار العنصر الثاني في قائمة ما؟




    :nth-child(2)

  19. أيٌّ من هذه يُعدُّ فئةً زائفةً وظيفيةً (functional pseudo-class) ؟




    :is()

  20. أيٌّ من هذه الخيارات لا يُعدُّ فئةً زائفةً وظيفيةً (functional pseudo-class) ؟




    :contains()
