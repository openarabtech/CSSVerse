أساسيات تصميم واجهة المستخدم User Interface

كيف يعمل مبدأ المقياس Scale في التصميم؟

نظري

ملاحظة: قد تستخدم بعض الأمثلة التفاعلية أكواد CSS لم تتعلمها بعد. لا تقلق بشأن محاولة فهم الكود بالكامل؛ فالهدف من هذه الأمثلة هو عرض نماذج لمفاهيم التصميم هذه، لتتمكن من فهم آلية عملها بشكل أفضل.

يشير (scale) "مقياس" شيء ما إلى حجمه.

عند النظر في مسألة التدرج (scaling) (أو تغيير الحجم) في تصميم الويب، فإنك تنظر إلى العلاقات الحجمية بين العناصر المختلفة، وكيفية تكيف هذه العناصر مع أحجام الشاشات المتنوعة.

يؤدي استخدام المقياس الصحيح للعناصر دوراً مهماً في التسلسل الهرمي البصري (visual hierarchy)؛ إذ تجذب العناصر الأكبر حجماً قدراً أكبر من الانتباه، مما يتيح لك توجيه المستخدمين عبر المحتوى بالطريقة التي ترغب بها.

على سبيل المثال، يجذب الفصل البصري بين العنوان والفقرة انتباه القارئ، ولكن ينبغي أن يكون الحجم مناسباً للحصول على نص لافت للنظر يشد القارئ إلى ذلك القسم (section). 


<style>
 body {
  font-family: sans-serif;
  padding: 20px;
  background-color: #fdfdfd;
  color: #333;
 }

 .section {
  margin-bottom: 40px;
 }

 .big-heading {
  font-size: 40px;
  font-weight: bold;
  margin-bottom: 12px;
 }

 .paragraph {
  font-size: 16px;
  max-width: 600px;
  line-height: 1.6;
 }
</style>

<div class="section">
 <div class="big-heading">اكتشف قوة التصميم الذكي</div>
 <p class="paragraph">
 
    لا يقتصر التصميم المتميز على الألوان أو الخطوط فحسب، بل يتعلق أيضاً بمقياس الحجم (التدرج في الأحجام). 
فالعنوان الكبير -مثل هذا العنوان- يجذب انتباهك على الفور، بينما توفر الفقرة التي تليه السياق والتفاصيل. 
ويُسهم التدرج الصحيح في الأحجام في رسم مسارٍ واضح تتبعه عين القارئ.
 
 </p>
</div>

معاينة:

اكتشف قوة التصميم الذكي

لا يقتصر التصميم المتميز على الألوان أو الخطوط فحسب، بل يتعلق أيضاً بمقياس الحجم (التدرج في الأحجام). فالعنوان الكبير -مثل هذا العنوان- يجذب انتباهك على الفور، بينما توفر الفقرة التي تليه السياق والتفاصيل. ويُسهم التدرج الصحيح في الأحجام في رسم مسارٍ واضح تتبعه عين القارئ.

لا يقتصر مفهوم القياس (Scale) (أو التحجيم) على النصوص فحسب، بل هو مهم أيضاً للصور؛ ففي حين قد يكون حجم صورة اللافتة (banner image) مناسباً لتخطيط سطح المكتب، إلا أنه قد يكون كبيراً جداً بالنسبة لتخطيط الأجهزة المحمولة.

من خلال تصغير حجم الصورة إلى نسبة أكثر ملاءمة، يمكنك الحفاظ على التأثير البصري مع ضمان بقاء المعلومات الموجودة على الموقع مرئية. 


<style>
 body {
  font-family: sans-serif;
  padding: 20px;
  background-color: #fefefe;
  color: #333;
 }

 .banner {
  max-width: 100%;
  height: auto;
  display: block;
  margin: 0 auto 20px auto;
  border-radius: 8px;
 }

 .content {
  max-width: 600px;
  margin: 0 auto;
  font-size: 16px;
  line-height: 1.6;
 }

 @media (max-width: 600px ){
  .banner {
    max-width: 90% ;
  }
  
  .content {
    font-size: 15px ;
  }
 }
</style>

 <p>
 
    تبدو صورة اللافتة هذه رائعة على الشاشات الكبيرة، لكنها تصغر تلقائياً عند عرضها على الأجهزة الأصغر حجماً.
وبهذه الطريقة، تظل الصورة تترك انطباعاً بصرياً قوياً دون أن تدفع المحتوى الأساسي خارج نطاق الشاشة.
يساعد ضبط حجم الصور بشكل صحيح في الحفاظ على التوازن وسهولة الوصول عبر مختلف تخطيطات العرض.
 
 </p>
</div>

معاينة:

تبدو صورة اللافتة هذه رائعة على الشاشات الكبيرة، لكنها تصغر تلقائياً عند عرضها على الأجهزة الأصغر حجماً. وبهذه الطريقة، تظل الصورة تترك انطباعاً بصرياً قوياً دون أن تدفع المحتوى الأساسي خارج نطاق الشاشة. يساعد ضبط حجم الصور بشكل صحيح في الحفاظ على التوازن وسهولة الوصول عبر مختلف تخطيطات العرض.

يُعد الحجم (Scale) عاملاً مهماً أيضاً فيما يتعلق بالتفاعل وإمكانية استخدام الموقع الإلكتروني فعلياً؛ فإذا لم يكن حجم النص في شريط التنقل (navigation bar) مناسباً، فسيواجه مستخدمو الهواتف المحمولة صعوبة في النقر على الروابط.

وإذا قمت بضبط الحجم بشكل مناسب، فستحصل على روابط لا تقتصر ميزتها على سهولة القراءة فحسب، بل تكون أيضاً أسهل في النقر عليها بالنسبة لمستخدمي الأجهزة المحمولة (mobile users). 


<style>
 body {
  font-family: sans-serif;
  padding: 20px;
  margin: 0;
  background-color: #fafafa;
 }

 .navbar {
  background-color: #004080;
  padding: 15px 20px;
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
 }

 .nav-link {
  color: white;
  text-decoration: none;
  font-size: 10px 15px;
  display: inline-block;
  border-radius: 4px;
 }

  .nav-link:hover {
  background-color: #0059b3;
 }

 @media (max-width: 600px ){
  .nav-link {
    font-size: 20px ;
    padding: 14px 18px ;
  }
 }
</style>

<nav class="navbar">

 <a href="#" class="nav-link">الخدمات</a>
 <a href="#" class="nav-link">الاتصال</a>
</nav>

معاينة:

الرئيسية نبذة عنا الخدمات الاتصال

تتعدد الجوانب التي تكتسب فيها "النسبة والحجم" (Scale) أهميةً في تصميماتك. وقد تناولنا الأساسيات، لذا ينبغي أن تكون لديك الآن فكرة جوهرية عن أهمية هذا العنصر.

أسئلة :

ما هو الغرض الأساسي من استخدام مقياس صحيح (correct scale) في تصميم الويب؟

1. لجعل كل شيء بنفس الحجم. ❌

2. لتوجيه المستخدمين عبر المحتوى. ✅

3. لاستغلال أكبر قدر ممكن من المساحة. ❌

4. لجعل النص أصعب في القراءة. ❌


لماذا قد تشكل صورة اللافتة الكبيرة (large banner image) مشكلة في تخطيط الهاتف المحمول؟

1. يستغرق تحميله وقتاً طويلاً. ❌

2. مظهره غير جذاب. ❌

3. يشغل حيزاً كبيراً جداً من الشاشة. ✅

4. يفتقر إلى القدر الكافي من التفاعلية. ❌


ما هو الاعتبار المهم عند تغيير حجم (scaling) عناصر التنقل (navigation elements) على الأجهزة المحمولة؟

1. جعلها صغيرة قدر الإمكان. ❌

2. ضمان سهولة النقر عليها. ✅

3. استخدام ألوان زاهية. ❌

4. إزالتها تماماً. ❌
