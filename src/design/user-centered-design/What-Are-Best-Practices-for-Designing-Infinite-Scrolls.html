ما هي أفضل الممارسات لتصميم التمرير اللانهائي Designing Infinite Scrolls ؟

نظري

ملاحظة: قد تستخدم بعض الأمثلة التفاعلية أكواد CSS لم تتعلمها بعد. لا تقلق بشأن محاولة فهم الكود بالكامل؛ فالهدف من هذه الأمثلة هو عرض نماذج لمفاهيم التصميم هذه، لتتمكن من فهم آلية عملها بشكل أفضل.

يُعد التمرير اللانهائي (Infinite scrolling) نمطاً تصميمياً يعمل على تحميل المزيد من المحتوى كلما قام المستخدم بالتمرير إلى أسفل الصفحة (scrolls down the page). وغالباً ما يُستخدم هذا النمط في مواقع التواصل الاجتماعي مثل "تويتر"؛ فعلى سبيل المثال، إذا كنت قد سجلت دخولك وترغب في الاطلاع على المزيد من التغريدات، يمكنك التمرير للأسفل ليتم تحميل تغريدات إضافية، وهذا مثال على التمرير اللانهائي (Infinite scrolling).

معاينة:

يُستخدم التمرير اللانهائي (Infinite scrolling) أيضاً كبديل لنظام تقسيم المحتوى إلى صفحات (Pagination). ويُعد هذا التقسيم نمطاً تصميمياً يعمل على تجزئة المحتوى إلى صفحات متعددة، وغالباً ما يُستخدم عندما تكون هناك كمية كبيرة من المحتوى المراد عرضه؛ ومن الأمثلة عليه ما يحدث عند البحث عن شيء ما في "جوجل"، حيث تظهر نتائج البحث موزعة على صفحات متعددة. ففي نظام تقسيم الصفحات (pagination)، يتعين عليك النقر على زر للانتقال إلى الصفحة التالية، بينما يتيح لك التمرير اللانهائي مواصلة التمرير للأسفل (scrolling down) ليتم تحميل المزيد من المحتوى تلقائياً.

index.js

let currentPage = 1;
const postsPerPage = 3;
const totalPosts = 9;
const totalPages = Math.ceil(totalPosts / postsPerPage);
const container = document.querySelector('.pagination');
const prevButton = document.querySelector('.prev');
const nextButton = document.querySelector('.next');

function renderPosts() {
  container.innerHTML = '';
  const start = (currentPage - 1) * postsPerPage;
  const end = start + postsPerPage;

  for (let i = start; i < end && i < totalPosts; i++) {
    const post = document.createElement('div');
    post.className = 'post';
    post.textContent = `المنشور ${i + 1}`;
    container.appendChild(post);
  }

  prevButton.disabled = currentPage === 1;
  nextButton.disabled = currentPage === totalPages;
}

prevButton.addEventListener('click', () => {
  if (currentPage > 1) {
    currentPage--;
    renderPosts();
  }
});

nextButton.addEventListener('click', () => {
  if (currentPage < totalPages) {
    currentPage++;
    renderPosts();
  }
});

renderPosts();

معاينة:

من الأمور الأخرى التي يمكن أخذها بعين الاعتبار إضافة زر "رجوع" ؛ إذ يتيح ذلك للمستخدمين العودة إلى الصفحة السابقة دون الحاجة إلى التمرير صعوداً إلى أعلى الصفحة بالكامل، مما يعزز تجربة المستخدم ويمنحهم تحكماً أكبر في تجربة التصفح.

قد تلاحظ أحياناً تصاميم تتضمن زر "العودة إلى الأعلى" (Back to the top)، والذي يعيد المستخدمين إلى بداية صفحة النتائج. ومن الأمور الأخرى التي ينبغي مراعاتها توفير مؤشر للتحميل (loading indicator)؛ إذ يجب أن يدرك المستخدمون بوضوح أنه يجري تحميل المزيد من المحتوى، وإلا فقد يظنون أن الصفحة معطلة.

index.js


const container = document.querySelector('.infinite-scroll');
const loadingIndicator = document.querySelector('.loading-indicator');
const backToTopBtn = document.getElementById('back-to-top');

window.addEventListener('scroll', () => {
  if (window.scrollY > 400) {
    backToTopBtn.style.display = 'block';
  } else {
    backToTopBtn.style.display = 'none';
  }

  if (window.innerHeight + window.scrollY >= document.body.offsetHeight) {
    loadMorePosts();
  }
});

backToTopBtn.addEventListener('click', () => {
  window.scrollTo({ top: 0, behavior: 'smooth' });
});

function loadMorePosts() {
  loadingIndicator.style.display = 'block';

  setTimeout(() => {
    for (let i = 0; i < 3; i++) {
      const post = document.createElement('div');
      post.className = 'post';
      post.textContent = `المنشور ${container.children.length + 1}`;
      container.appendChild(post);
    }

    loadingIndicator.style.display = 'none';
  }, 1000);
}

معاينة:

من الاعتبارات الأخيرة الحرصُ على إبقاء تذييل الصفحة (footer) متاحاً للمستخدم؛ فإذا كان التذييل (footer) يحتوي على معلومات مهمة، فينبغي أن يكون في متناول المستخدم في جميع الأوقات.

ختاماً، يُعد التمرير اللانهائي (infinite scrolling) وسيلةً ممتازةً لعرض المحتوى على موقعك الإلكتروني؛ ومع ذلك، ينبغي عليك مراعاة أفضل الممارسات عند تصميم هذه الميزة لضمان توفير أفضل تجربة ممكنة للمستخدم.

أسئلة :

ما هو التمرير اللانهائي (infinite scrolling) ؟

1. نمط تصميم يغير شريط التمرير في الصفحة. ❌

2. نمط تصميم يغير حجم الصفحة. ❌

3. نمط تصميم لتغيير لون خلفية الصفحة. ❌

4. نمط تصميم يقوم بتحميل المزيد من المحتوى أثناء قيام المستخدم بالتمرير لأسفل الصفحة. ✅


ما هو دور زر "تحميل المزيد" في خاصية التمرير اللانهائي؟

1. يُعيد تحميل الصفحة. ❌

2. يمنح المستخدمين التحكم في توقيت رغبتهم في رؤية المزيد من المحتوى. ✅

3. يتيح للمستخدمين العودة إلى المحتوى الذي تم تحميله سابقاً. ❌

4. يُقيّد كمية البيانات التي يمكن تحميلها. ❌


لماذا من المهم الحفاظ على إمكانية الوصول إلى تذييل الصفحة (footer) عند استخدام خاصية التمرير اللانهائي؟

1. يساعد ذلك في إبراز الألوان بشكل أكبر على الصفحة. ❌

2. يساعد ذلك في تسريع تحميل الصفحة. ❌

3. ليس من الضروري جعل تذييل الصفحة متاحاً وسهل الوصول إليه. ❌

4. لكي يتمكن المستخدم من الوصول إلى الروابط والمعلومات المهمة الموجودة في تذييل الصفحة في جميع الأوقات. ✅
