التصميم المتمحور حول المستخدم User-Centered Design

ما هو الكشف التدريجي Progressive Disclosure ؟

نظري

ملاحظة: قد تستخدم بعض الأمثلة التفاعلية أكواد CSS و JavaScript لم تتعلمها بعد. لا تقلق بشأن محاولة فهم الكود بالكامل؛ فالهدف من هذه الأمثلة هو عرض نماذج لمفاهيم التصميم هذه، لتتمكن من فهم آلية عملها بشكل أفضل.

الكشف التدريجي (Progressive disclosure) هو نمط تصميم يُستخدم لعرض المحتوى ذي الصلة فقط للمستخدمين بناءً على نشاطهم الحالي وإخفاء الباقي. يُجرى ذلك لتقليل الحمل الذهني وجعل تجربة المستخدم أكثر بديهية.

معاينة:


index.html


<link rel="stylesheet" href="styles.css">

<div class="progressive-disclosure">
  <button id="show-details-btn" aria-expanded="false" aria-controls="extra-content">
    عرض المزيد من التفاصيل
  </button>
  <div id="extra-content" class="hidden" tabindex="-1">
    <p>
      إليك تفاصيل إضافية لا تظهر إلا عندما ترغب في رؤيتها.
وهذا يحافظ على واجهة نظيفة ويقلل من العبء الإدراكي.
    </p>
  </div>
</div>

<script src="index.js"></script>

styles.css


.progressive-disclosure {
  font-family: sans-serif;
  max-width: 400px;
  margin: 20px auto;
}

#show-details-btn {
  background-color: #007bff;
  border: none;
  color: white;
  padding: 10px 16px;
  font-size: 1rem;
  border-radius: 5px;
  cursor: pointer;
  transition: background-color 0.2s ease;
}

#show-details-btn:hover,
#show-details-btn:focus {
  background-color: #0056b3;
  outline: none;
}

.hidden {
  display: none;
}

#extra-content {
  margin-top: 15px;
  padding: 10px;
  background-color: #f7f9fcff;
  border: 1px solid #ddd;
  border-radius: 5px;
}

index.js


const btn = document.getElementById('show-details-btn');
const content = document.getElementById('extra-content');

btn.addEventListener('click', () => {
  const isHidden = content.classList.toggle('hidden');
  btn.setAttribute('aria-expanded', !isHidden);

  if (!isHidden) {
    content.focus();
  }
});

على سبيل المثال، عند استخدام صفحة البحث في Google، ستكون معظم عمليات البحث بسيطة. لذا من المنطقي وجود واجهة مستخدم بسيطة مع خيارات قليلة جدًا. لكن في الحالات القليلة التي تحتاج فيها إلى بحث متقدم، توفر Google خيار بحث متقدم يكشف عن المزيد من الخيارات.

يمكنك العثور على خيار البحث المتقدم في قائمة الإعدادات على الصفحة الرئيسية لـ Google. أو يمكنك الذهاب إلى

google.com/advanced_search

مثال آخر على الكشف التدريجي هو زر "المزيد من التفاصيل" ("More details" button) على المنتجات في موقع تجارة إلكترونية. عند زيارة موقع مثل Amazon، سترى قائمة بصور المنتجات في فئات مختلفة. هذا يسمح للمستخدمين بالتسوق بسهولة دون أن يغمرهم الكثير من المعلومات.

إذا كان المستخدم مهتمًا بمنتج معين، يمكنه النقر على صورة المنتج لكشف المزيد من التفاصيل عنه. عرض كل المعلومات دفعة واحدة قد يكون مربكًا للمستخدم. لذا باستخدام الكشف التدريجي (progressive disclosure)، يمكن للمستخدم اختيار رؤية المزيد من المعلومات عندما يكون جاهزًا.

index.js


document.querySelectorAll('.details-btn').forEach((button) => {
  button.addEventListener('click', () => {
    const product = button.closest('.product');
    const details = product.querySelector('.product-details');
    const isHidden = details.classList.toggle('hidden');
    product.setAttribute('aria-expanded', !isHidden);

    if (!isHidden) {
      details.focus();
      button.textContent = 'Hide details';
    } else {
      button.textContent = 'More details';
    }
  });
});

فما هي بعض أفضل الممارسات لتصميم باستخدام تقنية الكشف التدريجي؟ الاعتبار الأول هو إبقاء كل المعلومات المهمة مرئية في جميع الأوقات. لا يجب أن يعاني المستخدمون للعثور على المعلومات الأساسية لأنها مخفية بميزات متقدمة إضافية.

اعتبار آخر هو توفير نقطة وصول واحدة للمستخدمين للوصول إلى ميزات أو معلومات إضافية. يمكن أن تكون زرًا أو رابطًا دائم الظهور في الصفحة. إضافة نقاط وصول متعددة قد تربك المستخدمين وتؤدي إلى تجربة مستخدم سيئة.

أثناء تصميم تطبيقاتك، فكر في تجربة المستخدم العامة وكيف يمكنك استخدام الكشف التدريجي لتسهيل العثور على المعلومات التي يحتاجها المستخدمون. عند تنفيذه بشكل صحيح، يمكن أن يحدث فرقًا كبيرًا في تجربة المستخدم العامة.

أسئلة :

ما هو الهدف الرئيسي من استخدام الكشف التدريجي في التصميم؟

1. زيادة عدد الميزات المرئية في جميع الأوقات. ❌

2. إرباك المستخدمين بكل الخيارات المتاحة. ❌

3. عرض المحتوى ذي الصلة فقط للمستخدمين بناءً على نشاطهم الحالي. ✅

4. جعل واجهة المستخدم أكثر تعقيدًا. ❌

كيف تنفذ Google الكشف التدريجي في صفحة البحث الخاصة بها؟

1. بعرض كل خيارات البحث دفعة واحدة. ❌

2. بتوفير خيار بحث متقدم يكشف عن ميزات أكثر عند الحاجة. ✅

3. بإخفاء شريط البحث خلف نافذة حوارية منبثقة. ❌

4. بتوفير صفحة بحث جديدة لكل استعلام. ❌


ما الذي يجب تجنبه لضمان تجربة مستخدم جيدة مع الكشف التدريجي؟

1. توفير نقطة وصول واحدة وواضحة للمعلومات الإضافية. ❌

2. استخدام نقاط وصول متعددة لإرباك المستخدمين. ✅

3. إبقاء المعلومات المهمة مرئية في جميع الأوقات. ❌

4. ضمان توفر المعلومات الإضافية عند الحاجة. ❌
