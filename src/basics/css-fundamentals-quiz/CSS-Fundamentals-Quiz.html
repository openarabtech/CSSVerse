اختبار أساسيات CSS

اختبار

  1. ما هي الأجزاء الرئيسية لقاعدة CSS؟




    المُحدِّدات وكتل الإعلان Selectors and declaration blocks.

  2. أي مما يلي يمثل الصيغة الصحيحة لقاعدة CSS؟




    
body {
 font-family: Arial;
}

  3. ما هي أنماط المتصفح الافتراضية؟




    قواعد CSS التي تطبقها المتصفحات تلقائياً.

  4. ما هي القيمة الافتراضية لخاصية العرض width؟




    auto

  5. ما الذي تحدده الخاصية min-height؟




    الحد الأدنى لارتفاع العنصر.

  6. أي مما يلي صحيح بخصوص المُحدِّد الشامل (Universal Selector *) ؟




    يمتلك أقل قيمة تحديد مقارنةً بأي مُحدِّد (selector) آخر.

  7. أي مُحدِّد يستهدف بشكل صحيح عناصر li الخاصة بقائمة مُرتَّبة (ordered list) ؟




    ol li {}

  8. أي مُحدِّد يستهدف عناصر الفقرة p الموجودة داخل عنصر div ؟




    div p {}

  9. أين تُطبِّق خاصية الهامش margin خصائص التنسيق؟




    المساحة خارج العنصر.

  10. أين تُطبِّق خاصية padding التنسيق؟




    المساحة داخل العنصر.

  11. أي عبارة مما يلي غير صحيحة بشأن العناصر ذات مستوى الكتلة (block-level elements)؟




    لا يمكنها شغل كامل العرض المتاح؛ إذ توجد قيود تمنعها من ذلك.

  12. أي عبارة تُعد خاطئة عند استخدام القيمة inline-block ؟




    وهي لا تشترك في الخصائص مع العناصر المضمنة (inline) أو عناصر مستوى الكتلة (block-level).

  13. ما هي العبارة الصحيحة بخصوص الكلمة المفتاحية !important ؟




    إنها تتجاوز أولوية التحديد (specificity) الخاصة بالمُحدِّدات الأخرى.

  14. ما هو الرمز الذي يسبق اسم مُحدِّد الفئة (class selector) ؟




    .

  15. أي مما يلي غير صحيح بشأن العناصر ذات المستوى المضمن (inline-level elements) ؟




    تبدأ دائماً في سطر جديد.

  16. أين يتم الوصول إلى أنماط CSS الداخلية؟




    تُكتب هذه الأنماط داخل قسم style الموجود ضمن عنصر head.

  17. ما هو ترتيب تطبيق خاصية الهامش الداخلي padding عند استخدام الصيغة المختصرة (shorthand) ؟




    top, right, bottom, left

  18. ما هو ترتيب تطبيق خاصية الهامش margin عند استخدام الصيغة المختصرة (shorthand) ؟




    top, right, bottom, left

  19. فيمَ تُستخدم أنماط CSS المضمنة (Inline CSS styles)؟




    تُستخدم لتنسيق العنصر مباشرةً، بدلاً من استخدام تنسيقات CSS الداخلية أو الخارجية.

  20. ما هو الرمز الذي يسبق مُحدِّد المُعرِّف (ID selector)؟
