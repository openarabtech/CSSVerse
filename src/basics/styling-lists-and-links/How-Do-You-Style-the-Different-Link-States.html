تنسيق القوائم (Lists) والروابط (Links)

كيف تُنسّق حالات الروابط المختلفة (Different Link States) ؟

نظري

توجد حالات مختلفة للرابط (different states of a link)، منها: رابط link ، تمت زيارته visited ، تمرير المؤشر فوقه hover ، التركيز عليه focus ، ونشط active. هذه الحالات (states) مهمة لمساعدة المستخدمين على التعرف على الروابط (links) وتوفير ملاحظات واضحة (clear feedback) بعد التفاعل معها، مما يحسن سهولة الاستخدام (usability) وإمكانية الوصول (accessibility).

يُعد تنسيق (Styling) حالات الرابط المختلفة (different link states) أمراً بالغ الأهمية لسهولة الاستخدام وإمكانية الوصول (usability and accessibility)، إذ يوفر مؤشرات بصرية حول الحالة الراهنة للرابط (current state of the link)؛ مما يساعد المستخدمين على معرفة الروابط (links) التي زاروها، والرابط الذي يتفاعلون معه حالياً، وما سيحدث عند النقر عليه.

بالنسبة للمستخدمين الذين يعانون من ضعف البصر أو إعاقات إدراكية، يمكن لهذه الأنماط المميزة (distinct styles) أن تجعل التنقل (navigation) أسهل بكثير وأكثر بديهية (intuitive).

علاوة على ذلك، تُعزز حالات الروابط الواضحة (clear link states) تجربة المستخدم الشاملة من خلال توفير تغذية راجعة (feedback) فورية حول تفاعلات المستخدم، مما يقلل من الارتباك ويُحسّن سهولة التنقل (navigability) في الموقع.

يمكن تنسيق هذه الحالات (states) باستخدام ما يُعرف بـ "الفئات الزائفة" pseudo-classes في CSS.

الفئة الزائفة (pseudo-class) هي كلمة مفتاحية تُضاف إلى المُحدِّد (selector) لتحديد حالة خاصة (special state) للعنصر المُحدَّد.

على سبيل المثال، يمكن لـ :hover تغيير لون الزر (button's color) عند تحريك مؤشر المستخدم فوقه، بينما يمكن لـ :visited تغيير لون الرابط (color of a link) الذي تمت زيارته مسبقاً.

تتيح لك الفئات الزائفة (pseudo-classes) تنسيق العناصر بناءً على حالتها (their state) أو تفاعل المستخدم (user's interaction) معها، دون الحاجة إلى ترميز إضافي (additional markup) في كود HTML.

تبدو صيغة "الفئة الزائفة" pseudo-class على النحو التالي، حيث يمثل A المُحدِّد (selector) ويمثل :B الفئة الزائفة pseudo-class : 


A:B {
 property: value;
}

لفهم كيفية تنسيق حالات الرابط المختلفة (different link states) بشكل أفضل، دعنا نلقي نظرة على بعض الأمثلة.

تُستخدم الفئة الزائفة :link لتنسيق الروابط غير المُزارة (unvisited links)، مما يشير إلى أنها قابلة للنقر (clickable).

إليك مثال على استهداف عنصر الرابط (anchor element) واستخدام الفئة الزائفة :link :

index.html


<link rel="stylesheet" href="styles.css">

<a href="/">رابط مثال</a>

styles.css


/* Normal state (unvisited link) الحالة العادية (رابط لم تتم زيارته) */
a:link {
 color: red;
}

رابط مثال

سيُغيِّر المثال أعلاه اللون الأزرق الافتراضي للرابط (link's default blue color) إلى اللون الأحمر red عندما يكون الرابط غير مُزار (unvisited).

تُستخدم السمة :visited لتنسيق الروابط التي تمت زيارتها أو النقر عليها مسبقاً (visited or clicked)، مما يساعد المستخدمين على تتبع الروابط (links) التي سبق لهم النقر عليها. إليك مثال على استخدام الفئة الزائفة (:visited pseudo-class) :

index.html


<link rel="stylesheet" href="styles.css">

<a href="https://openarabtech.github.io">التقنية العربية المفتوحة</a>

styles.css


/* Visited link رابط تمت زيارته */
a:visited {
 color: green;
}

سيقوم هذا الكود بتلوين الرابط باللون الأخضر green عند النقر عليه.

تُغيِّر الخاصية :hover نمط الرابط (link's style) عندما يُمرِّر المستخدم مؤشر الفأرة فوقه، مما يوفر إشارة بصرية تدل على أن الرابط تفاعلي (link is interactive). إليك مثال على استخدام الفئة الزائفة (:hover pseudo-class) :

index.html


<link rel="stylesheet" href="styles.css">

<a href="/">رابط مثال</a>

styles.css


/* Hover state حالة التمرير */
a:hover {
 color: green;
}

رابط مثال

سيقوم هذا الكود بتلوين الروابط باللون الأخضر green عند تمرير مؤشر الفأرة فوقها.

تُضيف السمة :focus أنماطاً (styles) حول الرابط عند التركيز عليه (focused)، مثلما يحدث عند التنقل (navigating) باستخدام لوحة المفاتيح (keyboard) أو لتعزيز إمكانية الوصول.

إليك مثال يستخدم الخاصية :focus لتطبيق إطار برتقالي مصمت (solid orange outline) عند التركيز على الرابط (link is focused).

index.html


<link rel="stylesheet" href="styles.css">

<a href="/">رابط مثال</a>

styles.css


/* Focus state حالة التركيز */
a:focus {
 outline: 2px solid orange;
}

معاينة:

رابط مثال

تُغيِّر الحالة :active أنماط الرابط (link's styles) أثناء النقر عليه، مما يوفر للمستخدم تغذية راجعة (feedback) فورية تفيد بأن إجراءه قيد التسجيل. إليك مثال على استخدام الفئة الزائفة (:active pseudo-class) :

index.html


<link rel="stylesheet" href="styles.css">

<a href="/">رابط مثال</a>

styles.css


/* Active state حالة نشطة */
a:active {
 color: pink;
}

أسئلة :

ما هي الفئة الزائفة (pseudo-class) في CSS المستخدمة لتنسيق الروابط التي لم تتم زيارتها (not been visited) ؟

1. :visited ❌

2. :link ✅

3. :hover ❌

4. :active ❌


ما هو التغيير البصري الذي تتضمنه عادةً حالة التمرير (hover state) في CSS؟

1. يصبح الرابط أكبر حجماً. ❌

2. يتغير لون نص الرابط. ✅

3. يصبح نص الرابط عريضاً. ❌

4. يُوضع خط تحت نص الرابط. ❌


أي فئة زائفة (pseudo-class) في CSS ستستخدمها لإضافة إطار خارجي مرئي (visible outline) حول رابط عند الانتقال إليه باستخدام لوحة المفاتيح (keyboard) ؟

1. :link ❌

2. :hover ❌

3. :focus ✅

4. :active ❌
