نظرية الألوان Color Theory

  • تعريف نظرية الألوان Color Theory Definition : هي دراسة كيفية تفاعل الألوان مع بعضها البعض وتأثيرها على إدراكنا. تتناول هذه النظرية العلاقات بين الألوان، وتناغم الألوان، والأثر النفسي للألوان.

  • الألوان الأساسية Primary Colors : وهي الأصفر Yellow والأزرق Blue والأحمر Red، وتُعدّ الألوان الجوهرية التي تُشتق منها جميع الألوان الأخرى.

  • الألوان الثانوية Secondary Colors : تنتج هذه الألوان من مزج كميات متساوية من لونين أساسيين. وتُعد الألوان الأخضر Green والبرتقالي Orange والأرجواني Purple أمثلة على الألوان الثانوية.

  • الألوان الثلاثية Tertiary Colors : تنتج هذه الألوان عن دمج لون أساسي مع لون ثانوي مجاور. ومن أمثلة الألوان الثلاثية: الأصفر المخضر Yellow-Green، والأزرق المخضر Blue-Green، والأزرق البنفسجي Blue-Violet.

  • الألوان الدافئة Warm Colors : تثير هذه الألوان - التي تشمل درجات الأحمر reds والبرتقالي oranges والأصفر yellows - مشاعر الراحة والدفء والألفة.

  • الألوان الباردة Cool Colors : وهي الألوان التي تشمل درجات الأزرق blues والأخضر greens والأرجواني purples، وتوحي بمشاعر الهدوء والسكينة والمهنية.

  • عجلة الألوان Color Wheel : عجلة الألوان هي مخطط دائري يوضح كيفية ارتباط الألوان ببعضها البعض. وتُعد أداةً أساسية للمصممين؛ إذ تساعدهم في اختيار مجموعات الألوان.

  • أنظمة الألوان المتجاورة Analogous Color Schemes : تضفي هذه الأنظمة طابعاً متناغماً ومريحاً؛ فهي تعتمد على ألوان متجاورة تقع بجانب بعضها البعض على عجلة الألوان.

  • أنظمة الألوان المتكاملة Complementary Color Schemes : تُنشئ هذه الأنظمة تبايناً عالياً وتأثيراً بصرياً قوياً؛ إذ تقع ألوانها في طرفين متقابلين على عجلة الألوان بالنسبة لبعضها البعض.

  • نظام الألوان الثلاثي Triadic Color Scheme : يتميز هذا النظام بألوان نابضة بالحياة، وتتكون عناصره من ألوان تبعد مسافات متساوية تقريباً عن بعضها البعض؛ فإذا تم الربط بينها، فإنها تشكل مثلثاً متساوي الأضلاع على عجلة الألوان.

  • نظام الألوان أحادي اللون Monochromatic Color Scheme : في هذا النظام، تُشتق جميع الألوان من لون أساسي واحد من خلال تعديل درجات سطوعه، وعتامته، وتشَبُّعه. يضفي هذا الأسلوب شعوراً بالوحدة والانسجام، مع الحفاظ في الوقت ذاته على وجود تباين.


طرق متنوعة للتعامل مع الألوان في CSS

  • الألوان المُسمّاة Named Colors : هي أسماء ألوان مُحددة مسبقاً تتعرّف عليها المتصفحات. ومن الأمثلة على ذلك: الأزرق blue، والأحمر الداكن darkred، والأخضر الفاتح lightgreen.

  • دالة rgb() : تشير اختصاراً RGB إلى الألوان الأحمر (Red) والأخضر (Green) والأزرق (Blue)، وهي الألوان الأساسية للضوء. تُدمج هذه الألوان الثلاثة بكثافات متفاوتة لإنتاج طيف واسع من الألوان. وتتيح لك دالة rgb() تحديد الألوان باستخدام نموذج الألوان RGB.

    index.html

    
<link rel="stylesheet" href="styles.css">

<p>لون RGB</p>

    styles.css

    
p {
 color: rgb(255, 0, 0);
}

    معاينة:

    لون RGB

  • دالة rgba() : تُضيف هذه الدالة قيمةً رابعةً، وهي "ألفا" (alpha)، التي تتحكم في شفافية اللون. وإذا لم يتم تحديدها، فإن قيمة "ألفا" تكون افتراضياً 1.

    index.html

    
<link rel="stylesheet" href="styles.css">

<div>خلفية بنظام RGBA</div>

    styles.css

    
div {
 background-color: rgba(0, 0, 255, 0.5);
}

    معاينة:

    خلفية بنظام RGBA

  • دالة hsl() : تشير اختصاراً HSL إلى درجات اللون (Hue)، والتشبع (Saturation)، والإضاءة (Lightness)؛ وهي المكونات الثلاثة الرئيسية التي تحدد اللون. كما تدعم الصيغة الحديثة لدالة hsl() قيمة اختيارية للشفافية (alpha)، تُضاف باستخدام الفاصل المائل /.

    index.html

    
<link rel="stylesheet" href="styles.css">

<p>لون HSL</p>
<p class="alpha">لون HSL مع قيمة ألفا (Alpha)</p>

    styles.css

    
p {
 color: hsl(120 100% 50%);
}

.alpha {
 color: hsl(120 100% 50% / 0.8);
}

    معاينة:

    لون HSL

    لون HSL مع قيمة ألفا (Alpha)

  • دالة hsla() : تُعد دالة hsla() وسيلة قديمة لإضافة الشفافية إلى ألوان HSL. وتُفضّل لغة CSS الحديثة استخدام دالة hsl() مع علامة الفصل / لتحديد قيم الشفافية (alpha).

    index.html

    
<link rel="stylesheet" href="styles.css">

<div>خلفية HSLA</div>

    styles.css

    
div {
 background-color: hsla(0, 100%, 50%, 0.5);
}

    معاينة:

    خلفية HSLA

  • النظام الست عشري Hexadecimal : يُستخدم الرمز الست عشري (المعروف اختصاراً بـ "hex code") لتمثيل الألوان في نموذج الألوان RGB. يشير مصطلح "hex" إلى نظام العد ذي الأساس 16، والذي يستخدم الأرقام من 0 إلى 9 والحروف من A إلى F. يمكن أن تتكون الرموز الست عشرية من 6 خانات، مثل #F498A2، أو من صيغة مختصرة مكونة من 3 خانات؛ وتصلح هذه الصيغة المختصرة عندما يتكرر الحرف نفسه مرتين في كل زوج من أزواج الصيغة الكاملة. على سبيل المثال، الرمز #2FB يعادل الرمز #22FFBB.

    index.html

    
<link rel="stylesheet" href="styles.css">

<h1 class="hex-text">نص بنظام ست عشري Hex</h1>
<p class="hex-bg">خلفية بنظام ست عشري Hex</p>

    styles.css

    
h1 {
 color: #FF5733;
}

.alpha {
 background-color: #4CAF50;
}

خاصية box-shadow

  • تعريف Definition : تُستخدم الخاصية box-shadow لإضافة ظل واحد أو أكثر حول عنصر ما.

  • قيم الإزاحة Offset Values : يجب عليك تحديد قيم للإزاحة الأفقية (offset-x) والإزاحة الرأسية (offset-y). تؤدي القيم الموجبة لـ offset-x إلى تحريك الظل نحو اليمين، بينما تؤدي القيم السالبة إلى تحريكه نحو اليسار. أما القيم الموجبة لـ offset-y فتُحرك الظل إلى الأسفل، بينما تُحركه القيم السالبة إلى الأعلى. إذا كانت القيمة 0 ، فلا داعي لإضافة وحدة قياس.

  • نصف قطر التمويه Blur Radius : تتحكم هذه القيمة الاختيارية في مدى ضبابية الظل. إذا لم يتم تحديدها، فستكون قيمتها الافتراضية 0 ، مما يؤدي إلى ظهور حواف حادة. وكلما زادت هذه القيمة، أصبح الظل أكثر نعومة.

  • نصف قطر الانتشار Spread Radius : تتحكم هذه القيمة الاختيارية في مقدار تمدد الظل أو انكماشه. إذا لم يتم تحديدها، فسيتم تعيينها افتراضيًا إلى 0.

  • لون الظل Shadow Color : يمكنك تحديد اللون باستخدام أسماء الألوان (named colors)، أو القيم الست عشرية (hex values)، أو الدوال rgb() أو rgba() أو hsl() أو hsla().

  • الكلمة المفتاحية inset : تؤدي إضافة الكلمة المفتاحية inset إلى وضع الظل داخل العنصر بدلاً من خارجه.

  • تطبيق ظلال متعددة للعناصر Multiple Box Shadows : يمكنك إضافة ظلال متعددة عن طريق الفصل بينها باستخدام الفواصل. يتم ترتيب الظلال في طبقات من الأمام إلى الخلف.

الصيغة الأساسية Syntax :


box-shadow: offset-x offset-y blur-radius spread-radius color;

التدرجات الخطية والشعاعية Linear and Radial Gradients

  • التدرجات الخطية Linear Gradients : تُنشئ هذه التدرجات مزيجاً تدريجياً بين الألوان على طول خط مستقيم. يمكنك التحكم في اتجاه هذا الخط باستخدام كلمات مفتاحية مثل to top (إلى الأعلى)، أو to right (إلى اليمين)، أو to bottom right (إلى الأسفل جهة اليمين)، أو باستخدام زوايا محددة مثل 45deg. كما يمكنك استخدام أي لون صالح في لغة CSS، وإضافة أي عدد ترغب به من نقاط التوقف اللونية (color stops).

    index.html

    
<link rel="stylesheet" href="styles.css">

<div class="linear-gradient">تدرج خطي Linear Gradient</div>

    styles.css

    
.linear-gradient {
 background: linear-gradient(45deg, red, #33FF11, rgba(100, 100, 255, 0.5));
 height: 40vh;
}

    معاينة:

    تدرج خطي Linear Gradient

  • التدرجات الشعاعية Radial Gradients : تُنشئ هذه التدرجات تأثيرات لونية دائرية أو بيضاوية تنطلق من نقطة مركزية.

    index.html

    
<link rel="stylesheet" href="styles.css">

<div class="radial-gradient">تدرج شعاعي Radial Gradient</div>

    styles.css

    
.radial-gradient {
 background: radial-gradient(circle, red, blue);
 height: 40vh;
}
