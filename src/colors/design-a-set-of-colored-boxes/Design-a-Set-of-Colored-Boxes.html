الألوان

تصميم مجموعة من الصناديق الملونة Colored Boxes

مختبر

في هذا المختبر، ستتدرب على استخدام ألوان CSS من خلال تصميم مربعات.


هيكل HTML الأساسي HTML boilerplate



<!DOCTYPE html>
<html lang="ar" dir="rtl">
 <head>
  <meta charset="UTF-8">
  <title>الصناديق الملونة</title>
 </head>
 <body>
 <!-- هنا تضع اكواد التطبيق -->
 </body>
</html>


قصص المستخدم User stories :

  1. ينبغي عليك ضبط "لون الخلفية" (background color) للعنصر body على القيمة #f4f4f4.

  2. ينبغي أن يكون لديك عنصر div يحمل الفئة color-grid ليضم كافة عناصر الألوان الخاصة بك.

  3. ينبغي أن تحتوي على خمسة عناصر div داخل العنصر .color-grid.

  4. يجب أن تحتوي عناصر div الخمسة جميعها على الفئة color-box بالإضافة إلى فئة أخرى بصيغة color#، حيث يمثل الرمز # رقم ترتيب عنصر الـ div المعني؛ فعلى سبيل المثال: color1 لعنصر الـ div الأول، و color2 للعنصر الثاني، وهكذا.

  5. يجب أن تحتوي الفئة .color-box على قيم محددة لكل من width (العرض) و height (الارتفاع)؛ وذلك حتى تظهر عناصر div الخاصة بك على الصفحة.

  6. يجب أن يحتوي العنصر .color1 على خاصية background-color تستخدم قيمة لونية بنظام الرموز الست عشرية (hexadecimal).

  7. يجب أن يحتوي العنصر .color2 على خاصية background-color تستخدم قيمة لونية بتنسيق RGB.

  8. يجب أن يحتوي العنصر .color3 على خاصية background-color تستخدم قيمة لونية محددة مسبقاً (على شكل كلمة).

  9. يجب أن يحتوي العنصر .color4 على خاصية background-color تستخدم قيمة لونية بتنسيق HSL.

  10. يجب ضبط خاصية background-color للعنصر .color5.

ملاحظة: تأكد من ربط ملف الأنماط (stylesheet) في ملف HTML وتطبيق قواعد CSS.


حل التطبيق :


index.html


<!DOCTYPE html>
<html lang="ar" dir="rtl">
 <head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>الصناديق الملونة</title>
  <link rel="stylesheet" href="styles.css">
 </head>
 
 <body>

  <div class="color-grid">
   <div class="color-box color1"></div>
   <div class="color-box color2"></div>
   <div class="color-box color3"></div>
   <div class="color-box color4"></div>
   <div class="color-box color5"></div>
  </div>
  
 </body>

</html>

styles.css


body {
 background-color: #f4f4f4;
}

.color-box {
 width: 150px;
 height: 150px;
 display: inline-block;
 box-shadow: 0 0 10px 0 #000000a1;
 border-radius: 8px;
}

.color1 {
 background-color: #ff0000;
}

.color2 {
 background-color: rgb(0, 255, 0);
}

.color3 {
 background-color: blue;
}

.color4 {
 background-color: hsl(200 100% 50%);
}

.color5 {
 background-color: rgb(255, 0, 255);
}
