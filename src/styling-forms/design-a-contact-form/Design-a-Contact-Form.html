قصص المستخدم User stories :

  1. ينبغي أن يكون لديك عنصر div يحمل الفئة form-container لاحتواء النموذج الخاص بك.

  2. يجب أن يتضمن العنصر .form-container عنصراً من نوع form.

  3. ضمن عنصر form، ينبغي أن تتوفر العناصر وحقول الإدخال التالية:

    • عنصر h2 يحتوي على نص.

    • حقل إدخال نصي للاسم، مع ضبط الخاصية type على القيمة text، وإضافة السمات id و name و required.

    • حقل إدخال بريد إلكتروني، مع ضبط الخاصية type على القيمة email، وتضمين السمات id و name و required.

    • حقل نصي (textarea) للرسالة، يتضمن السمات id و name والسمة required.

    • عنصر button يحتوي على النص إرسال وسمة type بقيمة submit.

  4. يجب أن يكون لكل عنصر من عناصر input و textarea عنصر label مقابل له، بحيث يتم ضبط السمة for في عنصر label لتشير إلى قيمة السمة id الخاصة بالعنصر المعني.

  5. يجب أن يحتوي العنصر .form-container على لون خلفية، بالإضافة إلى قيم لكل من border-radius و padding و width.

  6. يجب أن تحتوي عناصر على هامش ولون للخط.

  7. يجب أن تتضمن عناصر input و textarea قيماً لكل من:

    • width

    • padding

    • هامش في الأسفل.

  8. يجب أن يحتوي عنصر button على:

    • لون الخلفية.

    • حجم الخط بخلاف الحجم الافتراضي.

  9. ينبغي أن يحتوي الزر على تأثير يظهر عند تمرير المؤشر فوقه، بحيث يتغير لون الخلفية.

ملاحظة: تأكد من ربط ملف الأنماط (stylesheet) في ملف HTML وتطبيق قواعد CSS.


حل التطبيق :


index.html


<!DOCTYPE html>
<html lang="ar" dir="rtl">
 <head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>نموذج اتصال</title>
  <link rel="stylesheet" href="styles.css">
 </head>
 
 <body>

  <div class="form-container">
   <form>
    <h2>اتصل بنا</h2>
  
    <label for="name">الاسم:</label>
    <input
     type="text"
     id="name"
     name="name"
     required
    >
  
    <label for="email">البريد الإلكتروني:</label>
    <input
     type="email"
     id="email"
     name="email"
     required
    >
  
    <label for="message">الرسالة:</label>
    <textarea
     id="message"
     name="message"
     required
    >
    </textarea>
 
    <button type="إرسال">تسليم</button>
 
   </form>
  </div>
 </body>

</html>
